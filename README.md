# **Snowflake Road Safety Project**
Learning project using UK DfT road safety data and Snowflake.

## **Goals**
- Learn Snowflake fundamentals
- Build and ingestion pipeline
- Create staging and mart layers
- Implement data quality checks
- Explore Snowflake-specific features

## **Data Sources**
UK Department for Transport road safety datasets

## **Files**
- Collisions
- Vehicles
- Casualties

## **Status**
- Data downloaded
- initial profiling completed
- Snowflake account configured
- Raw layer created
- Statging layer created
- Mart layer created
